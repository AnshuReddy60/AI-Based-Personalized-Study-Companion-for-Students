# MindMuse – AI-Based Personalized Study Companion for Students

## 📘 Overview
MindMuse is an AI-based personalized study companion designed to help students study smarter and more efficiently.  
The application uses artificial intelligence to summarize learning materials, generate quizzes, create flashcards, and support structured learning through a user-friendly web interface.

This project was developed as a **major academic project** with a focus on practical AI integration and full-stack development.

---

## 🎯 Objectives
- Reduce the time spent on manual note-making  
- Improve understanding through concise summaries  
- Enable self-assessment using AI-generated quizzes  
- Support effective revision using flashcards  

---

## 🚀 Key Features
- 📄 **PDF Summarization** – Automatically generates concise summaries from PDF documents  
- 🎥 **Video Summarization** – Summarizes learning content from videos or YouTube links  
- 🧠 **Smart Quiz Generator** – Creates quizzes based on uploaded or provided content  
- 🗂️ **Flashcards & Summary Generator** – Helps with quick and effective revision  
- 📊 **Progress Tracking** – Tracks completed topics and learning progress  
- 🔐 **User Authentication** – Secure login and signup functionality  

---

- Natural Language Processing techniques  
- Machine learning utilities for summarization and quiz generation  

---

## 🏗️ Application Flow
1. User registers or logs in  
2. Learning material is uploaded or provided  
3. AI modules process the content  
4. Summaries, quizzes, and flashcards are generated  
5. Progress is stored and displayed to the user
